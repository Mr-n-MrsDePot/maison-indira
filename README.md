# Maison Indira

Independent luxury home-fragrance website for Maison Indira. Catalog, photography, prices, and checkout match the existing Shopify store; the site itself is its own brand, not a Shopify theme.

**Tagline:** Not just fragrance. An experience.

## Run

Double-click `START.bat`, or:

```text
cd D:\SystemHub\Projects\Active\maison-indira
npm install
npm run dev
```

Open [http://localhost:5222](http://localhost:5222).

## What it does

- Home, shop, product, maison, contact, returns, and bag
- Real Cloud Nine products and photos from the current store
- Bag stored in the browser; **Checkout** sends the same variant IDs to Shopify cart permalinks so payment and fulfillment stay on the existing store

## Stack

Vite + React + TypeScript. Node 24.15.0 / npm 11.18.0.
